Working `SKILL.md` examples land here as each lesson ships. Every one is a real skill that does something useful — cloneable, readable, and meant to be adapted rather than admired.

Each example is tagged so you know where it runs:

| Tag | Meaning |
|---|---|
| 🟣 **Claude** | Uses something Claude-specific (a Claude surface, tool, or workflow) |
| 🟢 **Codex** | Uses something Codex-specific |
| 🔵 **Both** | Pure `SKILL.md` — runs anywhere the standard is supported, including Cursor and Gemini CLI |

Most examples here will be **🔵 Both**, and that's the point: [the standard is open](../core/02-skills-standard.md) and the same folder works across Claude Code, Codex CLI, Cursor, and Gemini CLI. When an example is tool-specific, the README says exactly which part is, so you can adapt the rest.
