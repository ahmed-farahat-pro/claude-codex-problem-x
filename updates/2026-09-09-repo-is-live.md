# The repo is live

**2026-09-09** · Ahmed Farahat

---

I've been teaching this material one conversation at a time for months, and it doesn't scale. So it's a repo now, and it's free.

Problem X Academy covers what I actually think matters about AI agents: MCP, the Agent Skills standard, and getting work to run on a schedule without you. It covers **both Claude and Codex**, deliberately. Most content picks a side and quietly ignores the other, which is useless if you're trying to decide what to learn — so there's a folder for each, and a comparison guide for figuring out which one your work calls for. Concepts live in `/core/` and stay tool-agnostic, because those outlast whichever tool wins this quarter.

It updates daily. Both tools ship constantly and anything static goes stale in weeks. Corrections and PRs welcome — I'd rather be corrected in public than confidently wrong.
