# MCP Examples — Worked Servers and Connectors

**Status: placeholder**

---

Runnable MCP servers and connector configurations land here as each lesson ships. Small, readable, and built to be stolen from — a server that does one real thing well is worth more than a framework.

Each example is tagged by where it's been verified:

| Tag | Meaning |
|---|---|
| 🟣 **Claude** | Setup or config shown for Claude Code / Desktop |
| 🟢 **Codex** | Setup or config shown for Codex CLI / Cloud |
| 🔵 **Both** | Server code plus config for both clients |

The servers themselves are almost always **🔵 Both** — [MCP is a protocol](../core/01-mcp-protocol.md), so a server you write works with any client that speaks it. What differs is the client-side configuration, and where an example is tagged Claude or Codex it's usually that config, not the server.
